# Paper

`main.tex` is the single current paper source; `references.bib` holds its
citations. Build from this directory:

```bash
latexmk -pdf -interaction=nonstopmode -outdir=build main.tex
```

TinyTeX `latexmk`/`pdflatex` (4 pages, no warnings).
