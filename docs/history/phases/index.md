# Phases documentation

These folders record the prototype workstream. They are not the current AAAI
cluster procedure. Start at [SUPERVISOR_HANDOFF.md](../../../SUPERVISOR_HANDOFF.md)
and [docs/research/aaai-plan.md](../../research/aaai-plan.md).

Phase-scoped documentation is organized as:

- [`phase0/`](/docs/history/phases/phase0/index.md)
- [`phase1/`](/docs/history/phases/phase1/index.md)
- [`phase2/`](/docs/history/phases/phase2/index.md)
- [`phase3/`](/docs/history/phases/phase3/index.md)
- [`phase4/`](/docs/history/phases/phase4/index.md)
- [`phase5/`](/docs/history/phases/phase5/index.md)
- [`phase_overview/`](/docs/history/phases/phase_overview/index.md)

## Conventions

- Each phase folder contains methodology, acceptance, and completion evidence.
- Cross-phase summaries live in `docs/reports/`.
- Whole-repo non-phase knowledge lives in `docs/repo_handbook/`.
